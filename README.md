# CS 330: Computational Graphics and Visualization

## Portfolio overview

This repository shows my work in C++ and OpenGL throughout CS 330. My main project is a 3D desktop workspace built from basic geometric shapes, with textures, lighting, and controls for exploring the scene. I also completed a separate 2D collision animation.

### Featured projects

**Final 3D desktop workspace (Module 7)** — A computer workstation with a desk, monitor, keyboard, and mouse. I used transformations to position and size objects, wood/metal/monitor textures, shader-based lighting, and camera navigation. The monitor combines several basic shapes to create a more complex object.

**2D collision animation (Module 8)** — Colored circles move around a window, bounce off its edges, interact with colored bricks, and change color or direction when they collide with one another. The animation helped me practice collision checks and updating objects based on interaction.

### Technologies and skills

- C++, OpenGL, GLSL, GLFW, and Visual Studio 2022
- 3D modeling with basic meshes, scaling, rotation, and translation
- Texture mapping, surface materials, and Phong-style lighting
- Keyboard and mouse input, camera navigation, and projection modes
- Iterative development, collision detection, debugging, and code organization

## Reflection

### How do I approach designing software?

When I design software, I like to start by figuring out what the finished project should look like and then breaking it into smaller parts. For this project, I worked from a reference image and decided which basic 3D shapes would make sense for each object. I used a plane for the desk, boxes for parts of the monitor and keyboard, a pyramid for the monitor stand, and a scaled sphere for the mouse.

This project helped me get better at planning object placement, scale, textures, and lighting. I learned that even a simple-looking scene takes a lot of small decisions to make everything fit together. In future projects, I can use the same process of planning the smaller pieces before putting the whole program together.

### How do I approach developing programs?

I approached the development of my 3D scene one step at a time. I started with the basic objects and then added camera movement, textures, and lighting through the course milestones. I used C++ and OpenGL to make changes and tested the scene as I went. Sometimes I needed to adjust the size or position of an object or change how a texture looked before moving on.

Iteration was a big part of this project because I learned more with each milestone and went back to improve earlier work. I also became more comfortable keeping code organized in separate functions for objects, lighting, and other tasks. Compared with the beginning of the course, I now spend more time testing changes and thinking about how different parts of a program work together.

### How can computer science help me in reaching my goals?

Computer science is helping me build the programming and problem-solving skills I will need as I continue my degree and work toward a career in technology. This class gave me more experience with C++, graphics programming, object transformations, textures, lighting, and debugging.

I can apply these skills in future courses that involve programming, software design, or visualization. Professionally, the experience taught me how to take an idea, divide it into manageable tasks, and improve it through testing. Even if I do not work specifically with 3D graphics, those skills will still be useful when developing software and solving problems in a technical role.
